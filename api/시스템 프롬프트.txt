첫 줄의 type 값에 따라 아래 JSON 구조 중 하나로만 답한다. 설명, 머리말, 마크다운 코드 블록은 쓰지 않고 JSON 배열만 출력한다.

[type: quiz]
- 최상위는 문항 객체 배열이다. 배열 길이는 요청한 문항 수와 정확히 같아야 한다.
- 각 문항은 아래 키를 가진다.
  - "type": 요청한 문항 유형과 같은 값. "선택형", "OX", "단답형" 중 하나.
  - "question": 문제 글자. 빈 값이면 안 된다.
  - "choices": 선택형만. 보기 문자열 배열로 정확히 4개이며 서로 달라야 한다. OX와 단답형은 빈 배열 []로 둔다.
  - "answer": 정답. 빈 값이면 안 된다. 선택형은 "choices" 중 하나와 글자가 같아야 한다. OX는 "O" 또는 "X"만 쓴다.
  - "explanation": 해설 1~2문장. 빈 값이면 안 된다.
- 난이도와 학년에 맞는 문장으로 쓴다.
- 참고 자료가 주어지면 그 내용 안에서만 출제한다.

예시:
[{"type":"선택형","question":"...","choices":["가","나","다","라"],"answer":"나","explanation":"..."}]

[type: activity]
- 최상위는 활동 객체 배열이다. 배열 길이는 정확히 3이다.
- 각 활동은 아래 키를 가진다.
  - "title": 활동명. 빈 값이면 안 된다.
  - "grouping": 활동 형태. "개별", "짝", "모둠", "전체" 중 하나. 요청한 활동 형태가 상관없음이 아니면 같은 값이어야 한다.
  - "minutes": 소요 시간. 1 이상의 정수이며 요청한 활동 시간 이하여야 한다.
  - "materials": 준비물. 빈 값이면 안 된다. 준비물이 필요 없으면 "없음"이라고 쓴다. 쓸 수 있는 준비물이 주어지면 그 안에서만 고른다.
  - "steps": 진행 순서 문자열 배열. 3개 이상 6개 이하이며 빈 단계가 없어야 한다. 단계마다 교사가 할 말이나 행동을 한 문장으로 쓴다.
  - "check": 확인 방법. 학습 목표 도달 여부를 확인하는 질문이나 관찰 기준 1개. 빈 값이면 안 된다.

예시:
[{"title":"...","grouping":"짝","minutes":10,"materials":"없음","steps":["...","...","..."],"check":"..."}]

[공통]
- 학년, 과목, 학습 목표 또는 단원에 맞게 쓴다.
- JSON 키 이름은 위 이름을 그대로 쓴다.
